# Ejecutando Node.js

Colección de ejemplos y ejercicios pequeños para aprender de Node.js. Cada carpeta contiene un ejemplo independiente con un `main.js`, con archivos asociados y apuntes breves.

**Scripts**
1. Mostrando información del SO
2. Añadiendo texto a un archivo
3. Listando el contenido de una carpeta
4. Validando datos con una dependencia
5. Creando un servidor HTTP
6. Creando un servidor de notas
7. Creando una APP de notas

**Requisitos**
- Tener instalado Node.js (recomendado v14 o superior).
- Saber JavaScript.

**Cómo ejecutar un ejemplo**
1. En la terminal, muévete a la carpeta del ejemplo. Por ejemplo:

	```bash
	cd "1. Mostrando información del SO"
	```

2. Ejecuta el script principal con Node:

	```bash
	node main.js
	```

3. Algunos scripts piden instrucciones adicionales o tienen interactividad; sigue las indicaciones en la terminal.

Consejo: abre el código después de ejecutar el script para comparar la salida con lo que hace el programa; cada `main.js` incluye comentarios y apuntes.

**Notas**
- Los ejemplos están pensados para ser leídos y ejecutados directamente; no son aplicaciones listas para producción.
- Si un ejemplo usa dependencias, revisa el `package.json` dentro de esa carpeta (si existe) y ejecuta `npm install` antes de correrlo.
- Se asumirá que leerás la definición, tooltip o quick info de cada función o método utilizado para entender su propósito y uso.
- Los *apuntes* son más como curiosidades o aclaraciones relacionadas con el código de arriba suyo, no explicaciones detalladas de cada línea ni información repetida de una tooltip.

**Contribuir**
Si tienes mejoras, correcciones o nuevos ejemplos, abre un Issue o un Pull Request. Acepto sugerencias y ayuda para mejorar los apuntes.
